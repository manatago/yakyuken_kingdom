# Item Icon Prompts

`じゃんけんキングダム` のアイテムアイコンを nano-obanana で生成するためのプロンプト集。
生成画像に文字を入れず、アイテム名・効果・等級はゲーム UI 側で表示する。

## 共通ルール

- 出力は 1:1 の正方形。1024 x 1024 を基準にする。
- アイテム単体を中央に大きく配置する。小さく縮小しても輪郭で判別できることを優先する。
- 背景は透明が使える場合は透明。使えない場合は純白またはごく薄い灰白の無地にする。
- 文字、数字、読めるルーン、ロゴ、人物、手、カードの束、額縁、台座は描かない。
- 画風は、セル塗りのアニメ調ファンタジー RPG アイテムアイコン。輪郭線は明瞭、材質感は適度、強い写実表現や写真調は避ける。
- 光源は左上。アイテムの外周に控えめなリムライトを入れ、背景から分離する。
- 既存の UI と合わせ、暗すぎる配色にはしない。金属、紙、宝石、布の違いが一目で分かるようにする。

## 強度差分: 白紋・朱紋・金紋

確率操作アイテムは、同じ本体デザインに小さな紋を一つ加える。以下の個別プロンプトは、各アイテムを1枚ずつ生成できる完成形である。

| 強度 | 追加する指示 | 効果量 |
|---|---|---|
| 白紋 | `道具の正面に、白い陶器のような小さな紋。淡い白銀の光。` | 5% |
| 朱紋 | `道具の正面に、深い朱色の小さな紋。鮮やかな深紅の光。` | 10% |
| 金紋 | `道具の正面に、金箔と琥珀のような小さな紋。温かな金色の光。` | 15% |

紋は文字や数字にしない。円、三角、三つ巴に見えない抽象的な小印にする。
