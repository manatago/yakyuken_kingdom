## 自動検証

```sh
npm run typecheck
npm test
npm run test:ui
npm run smoke:game
npm run smoke:editor
```

既存のテスト探索機構により、追加テストはWindows/macOSの既存CIにも含まれる。
今回のローカル実行はmacOSのみ。Windowsの結果はPR作成後のCIで確認する。

- 単体：実JSONのアセット参照・遷移検証、全会話の再構築、2回の勝敗、全行程のセーブJSON往復。
  共用チェックの異常系は所持品・所持金・デッキ・保存地点・完了フラグ・台帳の不一致を検出する。
  既存の全手組合せ・グレード比較・80%境界・引分・偽造台帳・保存失敗テストも維持する。
- UI：セーブを事前投入せず「はじめから」から開始。実JSONの全会話を順に表示し、カード追加・削除・自動・準備完了、2回の勝負、締めの会話、終端まで操作する。
  1回目はパーで勝利を確認。2回目のUI結果は乱数に依存するため勝利固定にせず、台帳の件数・確認済み件数を確認する。
  80%境界の決定的検証は単体テストで行う。
- 再起動：グレード説明、デッキ準備、1回目の選択・未確認結果、2回目の選択・未確認結果、完了会話、終端。
  表示内容と保存地点が復元され、ロードだけではセーブのバイト列が変わらないことを確認する。
  各進行段階で所持カード9枚・所持金0を保持し、完了フラグと台帳が一致することを確認する。
- 配置反映：ソース・必要画像を一時プロジェクトへ複製。実エディタでカードボックスのX=1510、拡大率=0.9を保存し、対象ID以外と元バイト列のバックアップを確認する。
  複製プロジェクトのみ再ビルドし、新規開始と再起動後のContinueで同じ配置を確認する。
  元のJSON・実プレイヤーのセーブは変更しない。
