# Godot開発機能のElectron移植（統合タスク）

## 採用範囲（2026-10-15）

ユーザー指示：Godotで作成したエディタ機能と「途中から始める」も必須とする。
これらを含めずに移植全体の実装完了とは扱わない。マチルダ専用5項目の配置編集と、戦闘手前で止まる原本参照プレビューだけでは完了しない。

通常ゲームと開発用アプリは別ビルドにする、という既存方針を維持する。Godotを唯一の移植原本とし、操作の目的と編集可能な内容を移植する。GDScriptのソース行番号に依存して書き戻す仕組みは再導入しない。

### 保存・ゲーム反映・安全性

- 途中開始の開発プレイは通常プレイと別の保存領域を使用し、既存セーブを上書きしない。別ゲーム起動では別userData、ゲーム入口からは永続化しない一時セッションを使う。原本の初期状態を正規の保存スキーマへ変換して検証する。
- 開発アプリの保存先はプロジェクト内の許可済みコンテンツ／画像に限定する。通常ゲームには編集用IPC・任意ファイル書込・開発用画面を含めない。
- 編集結果はゲームが読む同じコンテンツへ反映する。プレビューだけ変わる、別のストーリーができる、原本再抽出で黙って消える、といった状態を避ける。参照原本と編集後データの関係を明記する。
- 未保存変更の保護、入力検証、同時保存競合、バックアップ、原子的置換、保存失敗時の旧データ保持を維持する。
- Godotのソース・画像や本番セーブを移植検証のために上書きしない。画像操作は隔離コピーで検証する。
