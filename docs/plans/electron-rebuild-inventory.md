# Electron再構築: 現行機能の移行台帳

対象計画: [Electron再構築計画](electron-rebuild.md)
対象タスク: 0.1 現行機能の移行台帳を作る

## 優先度の意味

| 優先度 | 意味 |
| --- | --- |
| 初期縦切り | MatildaチュートリアルをElectron版だけで開始・完了・保存・再開するために必要。 |
| 初回リリース | 初期縦切りの後、Electron版を通常プレイ可能な版にするために必要。 |
| 後続移行 | 初回リリースの範囲確定後に、独立した機能として移す。 |
| 対象外 | Electron版に移さない。 |

## ストーリー命令

`StoryCommands.gd` と `story/chapters/*.gd` は、GDScriptのResource・クラス・命令列としてストーリーを実行している。Electron版では命令をID付きコンテンツデータにし、レンダラーはそのデータだけを解釈する。

| 命令群 | 優先度 | Godot固有の実装 | 移植後に維持する振る舞い |
| --- | --- | --- | --- |
| 会話・地の文・会話帯 | 初期縦切り | `Line`、`Band`、Godot Control | 話者、本文、入力待ち、最小表示時間を順番に進行する。 |
| 背景・フィルター・間・簡易演出 | 初期縦切り | `Background`、`BgFilter`、`Pause`、Tween | 背景変更、暗転等の視覚状態、待機を再現する。 |
| 立ち絵の表示・非表示・位置・アニメーション | 初期縦切り | `ShowCharacter`、`HideCharacter`、`AnimatePortrait`、TextureRect | キャラクターIDに紐付く画像・位置・拡大・反転・表示状態を再現する。 |
| バトル開始・チュートリアル開始 | 初期縦切り | GDScript章パスを渡す `Battle` / `tutorial` 命令 | 会話から指定バトルへ遷移し、結果後に続きへ戻る。 |
| フラグ・ラベル・選択・シーケンス | 初回リリース | `SetFlag`、`SeqLabel`、GDScript Callable | 分岐と進行地点を安定IDで管理する。 |
| 端末演出・細かな動き・高度な帯演出 | 後続移行 | `TerminalEffect`、`MicroMotion`、専用Tween | 既存章で使う演出を、共通命令を増やしてから移す。 |

## 主要な移行境界

| 境界 | 現行 | Electron移行後 |
| --- | --- | --- |
| 表示 | GodotのScene/Controlと実行中ノード | Reactコンポーネントとシリアライズ可能な画面状態 |
| ゲームロジック | GDScriptのUI・章クラスに混在 | TypeScriptの純粋なドメインロジック |
| コンテンツ | GDScript章、クラス継承、`res://` パス | ID付きストーリー・バトル・レイアウト・アセットカタログ |
| 編集保存 | 行番号・正規表現でソースを更新 | スキーマ検証済みコンテンツデータを原子的に保存 |
| セーブ | GameState autoloadのJSON | 版番号付きのElectron版ゲーム状態JSON。旧Godotセーブは移行しない。 |

## 初期縦切りの固定範囲

Matildaチュートリアルは、タイトルから新規開始し、会話・立ち絵・Normalカード・N表示・手札・じゃんけん・保存/再開を通して完了できることを最初の開発上の到達点とする。配置編集は通常ゲームとは別の開発用ビルドで提供する。これは完成版の機能削減ではなく、現行の全ミニゲームも完成条件に含める。

## タスク0.3で確定した方針

詳細は[Electron再構築計画](electron-rebuild.md)の「確定した移行方針（タスク0.3）」に記録する。

- Windowsを主対象にし、macOSでも動作させる。
- 1920×1080を基準に縦横比を維持して拡大・縮小し、画面比率が異なる場合は余白を表示する。
- コンテンツ形式はJSONに統一し、開発用エディタは通常ゲームとは別ビルドにする。
- Godot版の既存セーブは移行しない。現行の全ミニゲームはゲーム本体の必須要素として移植する。
- 配布方式・自動更新・コード署名の詳細は本体完成後の公開準備で決める。
