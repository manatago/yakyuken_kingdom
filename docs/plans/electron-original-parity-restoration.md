# Godot原本との同一性回復（統合タスク）

## ストーリーの唯一の原本

- Godotのストーリーが唯一の原本である。Electron向けの別ストーリーは作らず、短縮・書き換え版を選択肢や互換経路として残さない。
- 原本から機械的に生成するJSONは原本の実行用表現であり、独立して執筆・編集する第二のストーリーではない。
- 通常プレイと検証画面は同じ原本データ・再生処理を使う。検証画面は照合用の入口に限定する。
- 既存の書き換え済みコンテンツ、専用の進行経路、それを正解とするテストは原本へ置き換え、不要になったものを撤去する。履歴はGitに残し、実行可能な代替ストーリーとして保存しない。
- 新規開始・続きから・戦闘内会話・ミニゲームを原本へ接続し、書き換え版へのフォールバックがないことを完了条件とする。
- 既存Electronセーブの扱いは原本との対応を調べて記録する。対応不能なセーブを黙って別ストーリーで再生したり、ユーザーのセーブを無断で削除・上書きしたりしない。
